# TOKAI INVEST — pacote com a logo TOKAI

Este pacote mantém o protótipo da versão visual de referência e utiliza a imagem `marca-tokai-invest.jpeg` como logo. Não foram feitas alterações no layout, nos textos, nas cores, na navegação, no gráfico de candles ou nas telas nesta preparação.

## Atualização no GitHub Pages
1. Abra a raiz do repositório que publica o aplicativo.
2. Substitua o `index.html` pelo arquivo deste pacote.
3. Envie `marca-tokai-invest.jpeg` para a mesma raiz (sobrescreva se já existir).
4. Faça o commit das alterações e aguarde o GitHub Pages publicar.
5. Recarregue o site com `Command + Shift + R`.

## Limitações
É um protótipo demonstrativo. Valores e operações são fictícios; não há integração real com MT5, backend ou notificações push.
