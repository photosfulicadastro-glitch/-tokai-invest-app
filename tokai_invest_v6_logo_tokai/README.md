# TOKAI INVEST — protótipo web v4

HTML/CSS/JavaScript sem dependências externas.

## Publicação no GitHub Pages
1. Faça backup do `index.html` atual.
2. Envie este `index.html` para a raiz do repositório usado pelo GitHub Pages e confirme a substituição.
3. Em Settings → Pages, mantenha Deploy from a branch e selecione a branch e `/(root)` que já publicam o site.
4. Aguarde a execução de Pages e recarregue o endereço publicado.

## Incluído
- 12 destinos de navegação: login, painel, candles, detalhes, histórico, notificações, sinal manual, conectar MT5, conta, espelhamento, operações e perfil.
- Gráfico de candles demonstrativos com M1, M5 e M15.
- Marcadores de compra/venda/saída e histórico selecionável.
- Layout responsivo desktop/celular.

## Limitações
Todos os candles, preços e resultados são fictícios. Não há backend, autenticação real, pagamento ou integração MT5. Não use credenciais reais.
